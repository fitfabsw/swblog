## 所有課程介紹

### 1. Claude 101

**適合對象：** 所有人，特別是剛開始接觸 Claude 的同事

這是整個 Academy 的起點。課程帶你了解 Claude 的核心功能，學習如何在日常工作中有效使用，包含實用的 prompting 技巧和工作流程建立。

你會學到：

- 如何寫出有效的 prompt
- Claude 的核心功能與使用情境
- 在真實工作任務中應用 AI 的習慣養成

> ✅ 筆者已完成並取得證書，推薦作為第一門課。

---

### 2. AI Fluency: Framework & Foundations

**適合對象：** 想建立 AI 協作系統性思維的所有人

這門旗艦課程不只教你怎麼用工具，而是提供一套完整的框架——**4D AI Fluency**，讓你能有邏輯、有效率、有道德地與 AI 系統協作。

你會學到：

- 與 AI 有效協作的結構化方法論
- 如何負責任地使用 AI
- 建立長期可持續的 AI 工作習慣

---

### 3. Building with the Claude API ⭐

**適合對象：** 任何想把 Claude 整合進產品的開發者

超過 8 小時的完整開發課程，這是整個 Academy 含金量最高的一門。從 system prompts 到 tool use，從 context windows 到架構設計，涵蓋實際打造 AI 產品的所有關鍵知識。

你會學到：

- System prompt 設計與最佳實踐
- Tool use / Function calling 整合
- Context window 管理策略
- 建構 AI 應用的架構模式
- 生產環境部署考量

> 💡 如果你正在做任何 API 整合或想把 AI 功能加入產品，從這門課開始。

---

### 4. Claude Code in Action

**適合對象：** 想提升開發效率的工程師

專門針對 Claude Code 這個開發者工具的實戰課程，展示如何用 AI 真正加速你的開發工作流程——不是玩具範例，而是真實的 coding 任務。

你會學到：

- 在實際開發流程中整合 Claude Code
- 用 AI 輔助 code review、debug、重構
- Agent 工作流程設計

> 💡 這是目前官方唯一的 Claude Code 認證課程。

---

### 5. Introduction to Model Context Protocol (MCP)

**適合對象：** 想打造 AI Agent 與自動化系統的開發者

MCP 是 Anthropic 推出的開放標準，讓 AI 能連接外部工具和服務。這門課教你從零開始用 Python 建立 MCP server 和 client，打通 AI 與既有系統的橋樑。

你會學到：

- MCP 的三大核心原語：tools、resources、prompts
- 建立 MCP server 與 client
- 連接資料庫、API 和外部應用

---

### 6. Model Context Protocol: Advanced Topics

**適合對象：** 完成 MCP 入門課後，想打造生產等級系統的開發者

深入 MCP 的進階實作，包含更複雜的整合模式和生產環境的傳輸機制。

你會學到：

- Sampling 與 notifications 機制
- File system 存取整合
- Transport 機制與生產環境部署
- 進階 MCP Server 架構模式

---

### 7. Introduction to Agent Skills

**適合對象：** Claude Code 使用者、想提升團隊 AI 使用一致性的工程師

教你如何建立可重複使用的「Skills」——讓 Claude 在正確時機自動套用正確指令，並在團隊間分享這些 Skills。

你會學到：

- 建立與設定 Claude Code Skills
- 跨團隊分享與管理 Skills
- 常見問題排查

---

### 8. Claude with Amazon Bedrock

**適合對象：** 使用 AWS 作為主要雲端平台的開發者與架構師

原本為 AWS 員工設計的認證課程，現在開放給所有人。涵蓋如何透過 Amazon Bedrock 整合和部署 Anthropic 的模型。

---

### 9. Claude with Google Cloud's Vertex AI

**適合對象：** 使用 GCP 作為主要雲端平台的開發者

完整介紹如何透過 Google Cloud Vertex AI 使用 Anthropic 模型，包含部署、監控和整合最佳實踐。

---

### 10. AI Fluency for Students

**適合對象：** 想在學習和職涯發展中有效運用 AI 的成員

幫助學習者建立 AI 協作技能，提升學習效率、職涯規劃和負責任地使用 AI。

---

### 11. AI Fluency for Educators / Teaching AI Fluency

**適合對象：** 有帶人、做內訓或教學職能的資深同事

幫助有教學和引導角色的人，將 AI 流利度整合進自己的教學實踐。如果你有 mentoring 或內部培訓的職責，這門課值得一看。

---

### 12. AI Fluency for Nonprofits

**適合對象：** 在非營利組織有志工或兼職的同事

針對非營利專業人員設計，在符合使命與價值觀的前提下提升 AI 應用能力。

## 給軟體部門的建議學習路徑

根據你的角色，以下是最建議的順序：

**軟體工程師**

`Claude 101` → `Building with the Claude API` → `Claude Code in Action` → `Intro to MCP` → `MCP Advanced` → `Agent Skills`

`Claude 101` → `AI Fluency: Framework` → `Building with the Claude API` → `Claude Code in Action` → `Teaching AI Fluency`

**剛接觸 AI 的同事**

`Claude 101` → `AI Fluency: Framework` → `AI Fluency for Students` → `Building with the Claude API`
